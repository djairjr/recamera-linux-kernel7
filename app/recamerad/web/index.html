            Topics
            
          
            Under : status (online/offline), target (ON/OFF),
            event (arrival/departure JSON), telemetry, snapshot (JPEG at every arrival),
            camera (a frame every few seconds), llm (the last LLM answer);
            commands detection/set, led/set, led/brightness/set. With discovery on, Home Assistant shows the camera
            as one device with these entities. For live video in Home Assistant add the RTSP stream
            (rtsp://user:password@camera/live) with the Generic Camera integration.

              Endpoints
              
          
              http(s)://…/chat/completions: the OpenAI chat API, spoken by OpenAI, Ollama
            (https://ollama.com/v1/chat/completions, or http://host:11434/v1/chat/completions
            on your network), OpenRouter, vLLM and others; the model must read images.
            ws(s)://…: a service of your own; one JSON message out
            (type, model, prompt, max_tokens, detection, image), the first message back is the answer.
